##  :heavy_exclamation_mark::memo:**1.Instalación**:memo::heavy_exclamation_mark:

Para poder ejecutar el programa debemos instalar el [jdk 18.0.2.1](https://download.oracle.com/java/18/archive/jdk-18.0.2.1_windows-x64_bin.exe) haciendo click aqui se te descargara directamente en el pc lo instalamos, debera asegurarse que lo insta en **" C:\Program Files\Java "**, despues entramos en windows y buscamos variables de entornos nos aprecera esta ventana y seleccionamos **variables de entornos**

![img](https://cdn.discordapp.com/attachments/1026233960335941692/1051938612482158683/image.png)



Se nos abrira esta ventana, seleccionamos **"Path"** y le damos a editar

![img](https://cdn.discordapp.com/attachments/1026233960335941692/1051938408097927248/Captura_de_pantalla_2022-12-12_200621.png)



Se abrira la siguiente ventana clickaremos en la variable de java y introducimos la siguiente la ruta **C:\Program Files\Java\jdk-18.0.2.1\bin** , le damos a enter para confirmar y aceptar.

![img](https://cdn.discordapp.com/attachments/1026233960335941692/1051939288725598298/image.png)



Descargamos de el enlace a github el archivo .zip, creamos una carpeta en C con el nombre que queramos y introducimos el archivo .zip que hemos descargado, lo descomprimimos y abrimos la carpeta  y Clickamos en el ejecutable y el programa comenzara a funcionar.

![](https://cdn.discordapp.com/attachments/1026233960335941692/1109898451422036028/image.png)
